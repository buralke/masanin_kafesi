# Maşanın Kafesi

Telefon tarayıcısında oynanan üç boyutlu orman kafesi oyunu.

TypeScript, Three.js ve Vite ile geliştirilmiştir.

## Geliştirme

```sh
cd game
npm ci
npm run dev
```

## Kontroller ve yayın

```sh
cd game
npm test
npm run build
```

GitHub Pages kaynağı GitHub Actions olarak ayarlandığında main dalındaki değişiklikler test edilip yayınlanır.

İlerleme aynı tarayıcıda saklanır. Kayıt dosyası oyun içinden indirilebilir veya yüklenebilir.

Seslendirme ve müzik dosyaları henüz eklenmemiştir.
